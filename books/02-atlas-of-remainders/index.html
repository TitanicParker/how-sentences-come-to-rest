Progressed colour logic

From rest to remainder.

The first book establishes the spare ground: sentences come to rest. This second book keeps that austerity but lets the colour system advance. Gold marks the operator, cyan marks orientation, violet marks terminal mode, and warm white marks the invariant that survives contraction.

The visual movement is slight but deliberate: from monochrome rest toward coordinated remainder. The style should feel like the first book continuing, not like a separate project.
